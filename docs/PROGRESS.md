# Etapas internas

1. Arquitetura: repositório próprio, Vite/React/TS/Tailwind; nenhum arquivo Finly alterado.
2. Design system: shell Graphite Garden, tokens, fontes locais, cinco presets e superfície de preview isolada.
3. Catálogos: adaptadores/snapshots de shadcn, React Bits, Magic UI e TweakCN; exemplos enumerados da árvore Git oficial Recharts. Aceternity bloqueado, três referências documentadas.
4. Demonstrações: seis componentes originais MIT e sete modelos Recharts. Bloqueios de licença React Bits/Aceternity preservados.
5. Editor: tokens, níveis de sobrescrita, cores, tipografia e geometria.
6. Playground: dnd-kit, teclado, layouts, comparação, histórico, viewport e fullscreen.
7. Previews: dez contextos visuais fictícios, sem motor ou transações financeiras.
8. Presets/favoritos/exportação: snapshots versionados, flush e validação, JSON/CSS/resumo.
9. Auditoria: Chromium desktop/mobile, correção de persistência imediata, contraste do rodapé e labels móveis.
10. Qualidade/publicação: TypeScript, lint, Vitest, browser/axe, build estático e documentação Cloudflare. Push remoto depende do acesso do ambiente ao repositório criado pelo proprietário.
